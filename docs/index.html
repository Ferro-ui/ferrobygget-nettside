Midt i det som skjer på Ulefoss

Ferrobygget ligger sentralt på Ulefoss, tett på utviklingen rundt Fensfeltet. For bedrifter som allerede jobber mot Fensfeltet – eller ønsker å posisjonere seg for mulighetene som kan komme – gir Ferrobygget en naturlig base.
